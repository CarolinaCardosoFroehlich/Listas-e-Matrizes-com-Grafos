# 📊 Implementação de Grafos em Python

Trabalho prático desenvolvido para a disciplina de Teoria dos Grafos / Estrutura de Dados do **2º ano de Computação**. O objetivo deste projeto é implementar e comparar as principais estruturas de representação de grafos em Python, contendo operações completas de manipulação e análise.

## Funcionalidades Implementadas

O sistema suporta as operações fundamentais em grafos, permitindo:
* Inserir e remover vértices
* Inserir e remover arestas (com suporte a grafos direcionados e não direcionados)
* Calcular e exibir o grau de cada vértice (entrada, saída e total)
* Verificar se existe uma aresta direta entre dois vértices
* Listar todos os vizinhos de um vértice específico
* Verificar se um determinado percurso (sequência de vértices) é válido
* Menu interativo via terminal com navegação controlada

---

## Representações Desenvolvidas

O projeto aborda as três formas clássicas de representação de grafos:
1. **Lista de Adjacência** (utilizando dicionários do Python)
2. **Matriz de Adjacência** (utilizando listas de listas)
3. **Lista de Arestas** (utilizando listas de tuplas)
